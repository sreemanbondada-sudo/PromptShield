# PromptShield

PromptShield is an explainable security gateway that detects prompt-injection attacks and sensitive-information leakage before user input reaches an AI application.

## Planned Features

- Prompt-injection detection
- Machine-learning classification
- Sensitive-information detection
- Explainable risk scoring
- Prompt sanitization
- Security-event dashboard

## Technology Stack

- Python
- FastAPI
- scikit-learn
- React
- SQLite
